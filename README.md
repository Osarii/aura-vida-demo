# Aura & Vida — Demo Premium V2

Demo frontend completamente interactivo para un consultorio / centro médico.

## Stack

- React 19
- TypeScript
- Vite
- CSS moderno
- jsPDF
- LocalStorage
- Datos mock
- Sin backend
- Sin base de datos real
- Sin autenticación

## Mejoras premium incluidas

- Navegación responsive
- Hero inspirado en el boceto de referencia
- Contadores animados
- Especialidades interactivas
- Búsqueda, filtros y ordenamiento de doctores
- Favoritos persistidos con LocalStorage
- Perfil avanzado de profesional
- Botón "Reservar con..." que precarga el flujo
- Wizard de reserva de 4 pasos
- Calendario visual
- Disponibilidad dinámica simulada
- Loading de disponibilidad
- Skeleton loading de profesionales
- Validaciones y estados visuales
- Confirmación con número de reserva ficticio
- "Mis citas" persistidas en LocalStorage
- Cancelación de citas demo
- Historial local
- Generación de comprobante PDF
- Descarga de archivo .ICS
- Apertura de Google Calendar
- Compartir confirmación por WhatsApp
- Toast notifications
- Animaciones por scroll
- Modo DEMO visible
- Restablecer demo
- Responsive desktop, tablet y móvil

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre la URL que muestre Vite, normalmente:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Importante

Toda la información es ficticia y se usa únicamente para demostrar el frontend.

Las reservas se guardan solo en `localStorage` del navegador. No se envían a un servidor y no representan citas médicas reales.
